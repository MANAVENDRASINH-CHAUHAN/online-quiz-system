# 🧠 AI-Powered Online Quiz System 🚀

## 📌 Overview
This is an AI-powered online quiz system designed for both students and faculty.  
It allows faculty to create quizzes manually or generate questions using AI, while students can attempt quizzes and view their results.

---

## ✨ Features

### 👨‍🏫 Faculty Panel
- Create quizzes manually
- Add questions manually
- 🤖 Generate quiz questions using AI
- Manage quizzes and questions

### 👨‍🎓 Student Panel
- Register & Login
- Attempt quizzes
- Submit answers
- View results instantly

### 🤖 AI Integration
- Automatically generate quiz questions based on topic
- Saves time for faculty
- Dynamic and intelligent question generation
